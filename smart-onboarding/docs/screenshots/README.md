## Rules

- Capture from a local build (`npm run build && npm start`) after **Reset demo data**, so only the fictional seed data is visible.
- Show **only fictional demo data**. Do not type real names, e-mail addresses or other personal information into any form before capturing.
- Do not edit, composite or mock up screenshots; each image must show the application as it runs.
- Keep the Demo Mode bar and the synthetic-data notices visible where they appear on the page.
- Browser window about 1440 × 900, light theme, 100% zoom. Crop browser chrome, bookmarks and extensions.
- Save as PNG with the file names below, then replace the matching row's status with the file link.
